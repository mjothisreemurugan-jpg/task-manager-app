# Task Manager App

A full stack MERN Task Manager application with authentication and user-specific task management.

## Tech Stack

- React.js
- Node.js
- Express.js
- MySQL
- Tailwind CSS

## Features

- User Signup
- User Login
- Add Tasks
- Delete Tasks
- Complete Tasks
- User-specific Tasks
- MySQL Database Integration

## Local Setup

### Clone Project

git clone <repository-link>

### Install Client

cd client
npm install

### Install Server

cd server
npm install

### Run Client

npm run dev

### Run Server

npm run dev
